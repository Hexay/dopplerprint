# doppler_print validation corpus

Real and synthetic recordings with known answers, for algorithm iteration and parity against DOPPLERGEIST.
Everything here is re-fetchable with `tools/fetch_corpus.py`. Large binaries are git-ignored (`.gitignore`).
Third-party media keep their upstream licences: **do not redistribute** (DOPPLERGEIST release data come from a
private repo; colsto's audio is all-rights-reserved).

## Layout

- `cases/<case_id>/`
  - `audio/`, `adsb/`, `dem/`, `source/` (publisher metadata and configs)
  - `baseline/`: `dopplergeist-release/` is archived checkpoint output; `rerun-YYYYMMDD/` is a local re-run
  - `truth.json`, `SHA256SUMS`
- `adsb/<day>/<region>.parquet`: adsb.lol day clipped to a region bbox, all aircraft types, native readsb fields.
  The schema is in the `tools/corpus/adsb.py` docstring, and the sidecar `.json` holds the bbox and counts.
  `adsb/2026-09-08/dopplergeist-derived/` holds DOPPLERGEIST's own ingests: the CONUS prop/unknown day (1.25 GB),
  the reference region, and the all-types faint window. `adsb/type-db/` holds the tar1090 ICAO type table.
- `dem/glo30/`: Copernicus GLO-30 tiles; `dem/geoid/`: EGM96 raster used by DOPPLERGEIST.
- `_downloads/`: raw upstream downloads and extracted archives. Of its ~20 GB, 17 GB is the five raw adsb.lol
  days. You can delete them once the clips exist; they are needed only to re-clip other regions. Treat these as untrusted input and never execute them.

## Ground-truth notes

- **oysterbay_20260908_colsto** (the video's own case). Audio is colsto's 1 h unlisted "Unknown location - raw
  audio" (youtu.be/4CxVxuMVkMc), decoded to a 48 kHz WAV by DOPPLERGEIST.
  - Answer: 40.876466, -73.524951. This is the author's top-ranked point, read from a video frame (combined score
    20.48), and it matches Street View at 19 Bayview Ave, Oyster Bay NY. Cross-checks: OspreyWatch nest 3916
    (40.8766, -73.5247) and DOPPLERGEIST's best fit (40.876932, -73.524982). The spoken "40.8735" is a garbled
    auto-caption.
  - Year: 2026, from the matched adsb.lol day.
  - Events: PC12 a1dfeb, CPA received 20:53:25 UTC. B350 ace391 at 21:08:46. The offset is 920.7 s.
  - Faint event: CPA at 20:38:51 UTC. The video says the clip is "8:37 pm UTC", which is unreconciled. Its flight
    is unconfirmed (DOPPLERGEIST picked CRJ9 a38237, 357 m off).
  - Recording start 2026-09-08T20:17:29.662Z: inferred by DOPPLERGEIST's locked fit, not an independent clock.
  - The video's spectrogram axes are +3600 s relative to this WAV, so colsto's original recording started about
    1 h earlier.
- **livermore_*** (Pathak, Zenodo 23424278, CC BY 4.0). Smartphone recordings of 40 GA/biz passages, May 2026,
  each with an ADS-B KML track and a UTC ridge CSV.
  - No recorder coordinate is published. It was trilaterated from the published ground-track offsets L
    (`_downloads/zenodo-23424278/trilateration.json`).
  - 37 passages fit one site, 37.663216 N, 121.781876 W, ~153 m MSL, with an RMS residual of 4.7 m.
  - The three 2026-05-09 passages (R08, R44, R45) do not fit it, missing by 1.5–4.7 km. They get a separate
    group fit (37.695539, -121.845009). Three tracks give no redundancy, so it is low confidence.
  - Audio sample-zero UTC is unpublished, so truth gives a start window bounded by the ridge.
- **nasa_uav_*** (data.nasa.gov rfk401li). Small UAVs with supplied GPS, so ADS-B does not apply. The `.mat`
  holds 4-mic pressure, UTC seconds-of-day (calendar date unresolved), mic NED table and GPS NED track. The origin
  is in `truth.json`.
- **dg_synthetic_*** and **dg_multievent_{3,4,6}**: DOPPLERGEIST synthetic fixtures with exact truth. Multi-event
  cases include remote decoy traffic.

## Baselines

- `baseline/dopplergeist-release/`: archived DOPPLERGEIST outputs (ranked.json, report.json, per-event
  csv/json/npz/png). Livermore cases carry the real-feature-benchmark fitted f0/speed/slant/CPA.
- `baseline/rerun-20261103/`: produced here with `tools/run_dopplergeist_baselines.sh`, using DOPPLERGEIST
  `main` in `reference/.venv-dopplergeist`. Each run took 5–29 s and peaked under 0.9 GB RSS.
  - The Oyster Bay two-event and faint runs reproduce the archived winners bit-for-bit.
  - The synthetic two-event winner moves ~25 m, as DOPPLERGEIST's own clean replay reports, and keeps the correct
    pair.

## Gaps

- The original video MP4 (YouTube is blocked here). It is not needed: the raw audio is in the case.
- adsb.lol days 2026-05-09 (3 passages, all outliers) and 2026-05-12 (2 passages) were not fetched, at
  ~3.2 GB each. Uncomment them in `tools/corpus/sources.py:ADSB_DAYS`, then run `adsb-fetch adsb-clip livermore`.
- WSU UAV dataset (doi:10.26183/07nm-4p35): rds.westernsydney.edu.au returns HTTP 403 from this IP.
- Freesound geotagged clips (DOPPLERGEIST survey): they have no recording UTC, so they cannot be matched to
  ADS-B, and preview URLs were 403/404. Skipped.
- AeroSonicDB: the publisher deliberately displaces its coordinates. Excluded.
- NASA `Flight Number Description.xlsx`: optional, and repeated S3 range timeouts left it unfetched. The
  protocol fields are in DOPPLERGEIST `benchmarks/nasa-session-cases-20261103.json`. The NASA `.mat` files are
  GPS-tracked UAVs, so there is no ADS-B and the calendar date is unresolved.
- The raw 2026-09-08 readsb day is kept in `_downloads/adsblol/` (3.9 GB) for re-clipping other regions or CONUS.

## Re-fetch

```bash
P="$(git rev-parse --show-toplevel)"
# needs gh auth with access to the private 1337isnot1337/DOPPLERGEIST repo
uv run --no-project --with numpy --with scipy --with pyarrow --with h5py -- \
  python -I $P/tools/fetch_corpus.py all          # or individual stages, see --help
# DOPPLERGEIST environment for baselines:
uv venv -p 3.14 $P/reference/.venv-dopplergeist
uv pip install -p $P/reference/.venv-dopplergeist/bin/python \
  -r $P/reference/DOPPLERGEIST/requirements/py314-linux.lock
uv pip install -p $P/reference/.venv-dopplergeist/bin/python --no-deps $P/reference/DOPPLERGEIST
$P/tools/run_dopplergeist_baselines.sh
```

Each stage is idempotent: it verifies hashes (release SHA256SUMS, Zenodo md5, pinned NASA sha256) and skips
existing outputs. To force a re-clip, delete `adsb/<day>/<region>.parquet`. All Python that parses downloads
runs under `python -I`. This host's IPv6 route blackholes, so the fetcher forces IPv4.
